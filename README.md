## How to run

Only `lib/`, `test/` and `pubspec.yaml` are included. Generate the platform folders first:

```bash
flutter create .
flutter pub get
flutter run            # or: flutter run -d windows / -d macos / -d chrome
```

`flutter create .` keeps the existing `lib/main.dart` and `lib/form_page.dart`.
